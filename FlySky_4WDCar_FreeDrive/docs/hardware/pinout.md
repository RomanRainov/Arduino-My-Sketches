# Pinout

| Pin | Role |
|---|---|
| D0/D1 | FlySky iBus hardware Serial |
| D2 | Servo |
| D3 | Right motor DIR |
| D4 | Left motor DIR |
| D5 | Right motor PWM |
| D6 | Left motor PWM |
| D13 | activity LED / SPI SCK conflict |
| A0 | battery pin passed to RR Driver |
| A4/A5 | I2C RGB controller through Driver |

No sonar/buzzer object is created by this standalone sketch.
