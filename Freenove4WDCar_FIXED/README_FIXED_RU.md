# Исправления FlySky_4WDCar_COMPLEX

## Обязательные изменения

1. В `setup()` добавлен `sonar.setup()`. Раньше выводы HC-SR04 не настраивались.
2. При переключении режима машина сначала останавливается, затем проигрывает индикацию режима.
3. В `RR_Freenove4WDCar_Sonar` добавлен timeout для `pulseIn()`. Без эха старый код мог зависать примерно на секунду.
4. Отключена отладочная печать батареи в `Serial`, потому что этот UART занят приёмником FlySky iBus.

## Automatic_Obstacle_Avoidance

- Удалены неинициализированная сумма и ошибочный локальный `motorRun()`.
- Команды выполняются через `RRFreenove4WDCarDriver` в его шкале 0..100.
- Сканирование и манёвры реализованы как автомат состояний без длинных `delay()`.
- Сохранена исходная логика Freenove: скан слева/по центру/справа, отход назад и поворот в более свободную сторону.

## Automatic_Stay_Close_To_Obstacle

- Исправлено направление регулятора расстояния.
- Сканирование продолжается постоянно, а не прекращается после первого найденного объекта.
- Движущийся объект определяется по изменению расстояния между последовательными картами сканирования.
- После захвата приоритет отдаётся прежнему и соседним направлениям, чтобы не перескакивать между объектами.
- Машина поворачивает к объекту и удерживает расстояние 30–50 см.
- При потере объекта машина останавливается и продолжает сканирование.
